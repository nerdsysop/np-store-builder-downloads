**Prefer not to install anything?** Use it in your browser: https://np-store-builder.vercel.app/builder

## Installing

- **Windows:** run the `.exe` and follow the steps. If Windows says it protected your PC,
  click **More info → Run anyway**.
- **Mac:** open the `.dmg` and drag **NP Studio Store Builder** into **Applications**.

The app updates itself when a new version comes out.
